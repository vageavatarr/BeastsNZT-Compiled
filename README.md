# Готовая сборка Beasts PRO

Репозиторий выпуска плагина Beasts PRO для ExileAPI. Он содержит DLL плагина и описание её зависимостей. Для работы требуются совместимая версия ExileAPI и лицензия.

| Файл | Назначение |
|---|---|
| [Beasts.dll](Beasts.dll) | Собранная библиотека плагина |
| [Beasts.deps.json](Beasts.deps.json) | Метаданные зависимостей .NET |

За сведениями о совместимости конкретной сборки и доступе обращайтесь к владельцу проекта.
